# Deployment Checklist

## Before Deployment
- [ ] Changes reviewed.
- [ ] Tests completed.
- [ ] Build completed successfully.
- [ ] Environment variables confirmed.
- [ ] Database migrations reviewed.
- [ ] Security implications reviewed.
- [ ] Rollback plan considered.

## Cloudflare
- [ ] Correct project/environment selected.
- [ ] Build command verified.
- [ ] Output directory or deployment target verified.
- [ ] Runtime compatibility checked.
- [ ] Required bindings/configuration checked.
- [ ] Production secrets configured through secure settings.

## After Deployment
- [ ] Deployment logs reviewed.
- [ ] Homepage loads.
- [ ] Authentication tested.
- [ ] Core user workflow tested.
- [ ] Admin permissions tested.
- [ ] Database operations tested safely.
- [ ] Error monitoring checked.
