💰 Host Settlement Process

Settlement Method
All payouts are processed automatically via CHIP Send API after the host confirms check‑in.
Settlement Timeline
Payout is triggered immediately upon check‑in confirmation by the host.
Funds are sent to the host's bank account via CHIP Send within 1–4 business days (depending on bank processing).
Fees & Deductions
• Service Fee: 11% on the booking subtotal (per night × nights)
• Gateway Fee: RM 1.10 per transaction (to cover CHIP Collect costs)
• Host Receives: The full base amount (nightly rate × nights) — no additional deductions
The platform fee is retained to cover verification, support, and payment processing costs.
Example Settlement
• Booking: RM 200/night × 3 nights = RM 600 base
• Service Fee (11%): RM 66
• Gateway Fee: RM 1.10
• Guest pays: RM 667.10
• Host receives: RM 600 (via CHIP Send)
• Platform retains: RM 67.10
Settlement Terms
• Payouts are only triggered after the host confirms check‑in using the guest's 6‑digit check‑in code.
• This ensures the guest has actually arrived and prevents fraud.
• Funds are sent directly to the bank account registered by the host during the approval process.
• The platform is not responsible for bank processing delays.
