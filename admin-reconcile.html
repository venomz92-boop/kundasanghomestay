Reconcile Stuck Payout

Use this page only when a booking is stuck with a payout marker (status "Completed - Payout Unknown" or an unresolved attempt marker). You must first log into your CHIP dashboard and search for the reference KDH-<bookingId> to determine whether a payout exists.

⚠️
Before you use this page:
  1. Open your CHIP Send dashboard in a new tab.
  2. Search for the reference number of the stuck booking.
  3. Note whether a payout exists, and if so its payout ID.
  4. Come back to this page and choose the matching option below.
Choosing the wrong option can cause a duplicate payout or hide a payout that already succeeded. The confirmation text is there to slow you down.
